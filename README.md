# focal-obsidian-cello

## Reasoning

I chose to create an interactive ambient cello visualizer that blends obsidian (dark glassy) aesthetics with focal point interactions. The concept is simple: create a dark, moody environment with glowing cello strings that respond to mouse movement, creating harmonic visualizations.

Key design decisions:
- Dark theme with obsidian-like gradients and glassmorphism for a sophisticated look
- Canvas-based animation for smooth, performant visuals
- Interactive elements - mouse movement affects string vibrations and particle effects
- Subtle ambient animations to create a meditative, beautiful experience
- Minimal code approach - vanilla HTML, CSS, JS with no dependencies
- Responsive design that works across screen sizes

The app creates an immersive experience where the user can interact with virtual cello strings, generating beautiful trails and glows. It's abstract but evokes the elegance of a cello in a dark concert hall.
